# Carboxyhemoglobin – System Crash Simulation

⚠️ **WARNING**: This application may cause intense light flashes and sudden loud sounds. Do not run if you are sensitive to light or have epilepsy.

**IMPORTANT**: This is a simulated system crash. No actual damage is caused to your computer. It is designed to test system behavior under stress in a virtual machine environment.

## Features
- Full-screen light flashes and glitch effects
- Random low-frequency sound pulses
- Fake antivirus disabling messages
- System settings modification (wallpaper, taskbar, volume)
- Disk usage simulation
- Browser search simulation (kernel panic)
- Automatic system restart after 10-25 minutes

## How to Run
1. Extract all files to the same folder.
2. Run `Carboxyhemoglobin.bat` as Administrator.
3. Press any key to continue after the warning.
4. To stop, close the command window or press CTRL+C.

## Note
This is for educational and entertainment purposes only. Use only in a virtual machine environment.
